## Scope and limits

This is a hybrid research prototype. Both copies still load Python. Maxima supplies authoritative ordinary STACK answer-test verdicts without a SymPy answer-test fallback. CTM/Pyodide prepares variants, validates inputs, drives PRTs, formats bounded diagnostics and runs PythonChecker.

All authored rows execute through the question-tests control. One selected full-credit authored response per variant is also entered through the student editors; this does not mean every incorrect authored response was typed through those editors.

Chromium is the verified browser. The static host uses an isolation service worker without application/resource caching; the first visit can reload once. Broader browser, memory, offline/exam, general native orchestration and production backend registration remain later work. The earlier timing comparison establishes no performance advantage.
