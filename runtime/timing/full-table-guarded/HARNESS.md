# Guarded six-cell STACK timing table

This is a separate diagnostic derivative of the frozen original clean table in `full-timing-table`. The original files and their review remain unchanged. Original clean timings have a startup-stdout visibility limitation: the accepted child consumes ordinary output privately and can emit READY after an earlier load error. Missing historical stdout is an unexcluded risk, not a retrospective claim that an original clean trial failed.

This guarded version admits the same exact three producer artifacts and original 87-file sites, then changes only the staged benchmark copy of `runtime/maxima-child.js`. All runtime assets, startup strings, manifests, source/FAS payloads and the session wrapper retain their admitted bytes. The child is derived from the pinned original SHA256 `24125f846a4fb7d3f57c82327bb5dfe267998682858d25369045de44d1ec1e0b` by the same helper used in the filesystem-error A/B experiment. All three profiles and both source/FAS modes must use the identical derived child hash. Per-profile proof JSON records original/derived bytes, helper-fragment identity and each unique replacement anchor. The original source identity remains separate from the benchmark identity.

The observer uses the original stdout line parser and bounded tail. Before READY, it checks ordered LOAD-BEGIN/LOAD-END/READY markers and latches anchored loadfile, Lisp-error, debug-error and syntax-error diagnostics. The first fatal emits a bounded diagnostic receipt and error; failed state suppresses all later READY lines. Original child failures also latch failure. Exactly one successful receipt is required both after initialization and after final message draining. Failure terminates the session and retains receipt, first fatal and tail. The tail is at most 16,384 characters; truncation is explicit. Stderr is not interposed and remains available only through retained browser console diagnostics. These checks do not prove a same-evaluation root-load return or exclude every possible startup failure.

The CLI remains `run.mjs --old-trusted-root ROOT --candidate-trusted-root ROOT --profiles-root PROFILES --admission FILE --output EVIDENCE --repetitions 3`. The unchanged plan is 3 runtime profiles × source/own FAS × cold/reload ×3 =36 measurements. Profile order rotates and each profile uses both source/FAS orderings. Every cold/reload pair gets a fresh browser/profile; reload uses the same page/context only after confirmed CAS termination, poisoned state and rejection of calls. Each measurement gets a fresh outer worker, CAS child, buffers and token. The original 300-second measurement watchdog remains.

First logical validation precedes grades or warmup. The table measures readiness/STACK/wasm phases, first positive and negative AlgEquiv grades, ten warm grades and arithmetic calls. The sum of readiness, first logical and first positive is a synthetic sequence metric, not complete UI latency. All ten typed controls, STACK policy, admitted native prepare/validate/prt replays, 100 full-GC/live-object checks, caught-error recovery and four plotting-policy checks remain required. Native-program timings are warm replay checks, not cold first-native-question latency. FAS modes require the matching FAS hash, exactly one FAS read and zero source-entry fallback.

Every attempted measurement retains partial and final sample JSON. The compact report includes original package identities, derived-child proof hashes, startup-guard status, correctness, termination and timing summaries without repeating embedded source text. Shared observer parsing and one receipt add overhead; these are guarded timings rather than pristine-wrapper timings. There are no TRACE, CPU, FS or Worker-constructor observers, no rebuild of admitted artifacts and no performance/default-promotion assumption. n3 medians remain descriptive.

Data-only tests cover the unchanged 36-cell plan and typed/lifecycle boundaries, missing/fatal/delayed-duplicate receipt rejection, exact original child derivation, marker ordering and bounded output. They replay the actual failed draw.lisp stdout tail from artifact12578335489 with an explicitly synthetic BEGIN prefix. Local tests do not execute browser/CAS/Lisp/Wasm/artifact programs. Publication and actual runtime acceptance require the separate admitted-source bindings and independent integration review.
