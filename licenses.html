Licences and sources

Third-party software and content that this site redistributes

This site serves files that were written by other people. This page lists them, the licence each one is distributed under, where that statement comes from, and where the matching source can be found. The licence texts are in the LICENSES/ folder of this site (27 text files, linked below file by file) and in the repository’s site/LICENSES/ folder (the same files; the repository copy becomes visible on the main branch once this page is merged). The page describes what is provided. It is not legal advice and does not claim that every condition of every licence has been checked.

The native board bundle additionally carries its own licence inventory, original licence files and source provenance. Those files are additional to the 27 texts above.

Everything below was checked on 2026-10-22 and 2026-10-23 against the files deployed on this site. The site also serves preview copies of research branches under previews/research/ (2026-10-native-stack and 2026-10-runtime-feasibility at the time of checking). Their maxima-runtime/ binaries and maxima.js have the same SHA-256 as those of the main site, and their stack-sources.json names the same STACK commit. This page covers those copies as well. “Evidence” means a notice inside a shipped file, a licence file in the upstream source tree at the stated version, or both. Where neither could be found the entry says so.

Maxima, ECL and gnuplot runtime

The Maxima runtime in maxima-runtime/ is the WebAssembly build made by Marius Gerbershagen: an Emscripten port of Maxima running on ECL, deployed at https://maxima-on-wasm.pages.dev/. Its source is published at https://gitlab.com/mgerbershagen/maxima (branch emscripten-port-deployed).

  • The files are copied byte for byte from that deployment. Each file’s SHA-256 is recorded in runtime-assets.json and checked when the site is built. This site has not modified, rebuilt or patched them. runtime-preload.json is assembled by this project from the same unmodified files (their bytes, base64-encoded) so that they load in one request.
  • The port’s source is published at the repository above (branch emscripten-port-deployed). This project could not confirm that this branch contains the Maxima commit (813903d33) or the ECL source id (e4bdb2e5...) named by the binaries, and has not compared the branch with the files: GitLab could not be read from its build environment.
  • A runtime built by the CTM project from pinned sources, with its full build recipe, sources and licence files published beside each release, is planned; see §6 of the system design audit. Until then the upstream deployment is the reference for these files.

Notes on the runtime

Maxima

  • Maxima’s COPYING consists of a preface about the U.S. Department of Energy and the text of the GNU GPL version 2; the whole file is in LICENSES/Maxima-COPYING.txt. It was read at Maxima’s branch-5_49-base tag (cce856a60952c971e6f3604706335455c9a46fca) in a GitHub mirror of Maxima’s repository, https://github.com/rtoy/maxima. The shipped commit (813903d33, from the version string) is not in that mirror, so it is presumably on the port branch; it could not be inspected here. The version string means 90 commits after the 5.49 branch point of December 2025.
  • The COPYING file does not say “or later”. Most Maxima core source files carry only a copyright line and no licence text. Whether a given core file is “GPL-2.0-only” or “GPL-2.0-or-later” is therefore not stated in the files examined. GitLab’s page for COPYING on the port branch (read on 2026-10-22) labels the project “GNU General Public License v2.0 or later”.
  • maxima.wasm contains the paths of 156 files of the port’s src/ and share/utils/ trees (for example src/mlisp.lisp). Comparing those with the branch-5_49-base tag, these files carry notices other than the project licence:
    • intl.lisp: copyright 1999-2010 Paul Foley, an MIT-style permission notice. The notice from the header of that file is reproduced verbatim in LICENSES/Maxima-intl.lisp-notice.txt (no SPDX identifier assigned here).
    • getopt.lisp: copyright 2003 Kevin M. Rosenberg. The file’s licence is Maxima’s LICENSES/getopt-license.txt (three-clause BSD terms), reproduced unchanged in LICENSES/Maxima-getopt-license.txt.
    • maxmin.lisp, nummod.lisp: Lisp Lesser GNU Public License (LLGPL: Franz’s preamble, LICENSES/LLGPL.txt, plus the GNU Library General Public License version 2 or later, LICENSES/LGPL-2.0-or-later.txt). The share file mring.lisp has the same notice (see the share table).
    • rand-mt19937.lisp: derived from public-domain CMUCL code and the Mersenne Twister, noted as placed in the public domain.
    • numerical/f2cl-lib.lisp: header “Copyright (c) University of Waikato, Hamilton, New Zeland 1992-95 - all rights reserved”; no licence text.
    • pregexp.lisp (Dorai Sitaram): no licence text in the file.
    • numerical/slatec.lisp, and the contents of maxima-slatec.fas and maxima-quadpack.fas: Lisp translated by f2cl from the Fortran of the SLATEC library (which includes QUADPACK), obtained from netlib, according to Maxima’s src/numerical/slatec/README. The licence status of the Fortran originals is not stated there and was not determined here.
  • The nine maxima-*.fas files are compiled Maxima modules. They contain Maxima’s symbol names and no licence text of their own.

ECL, GMP and the garbage collector

  • libecl.so contains the strings 26.3.27 and the source id shown in the table, and the banner “Copyright (C) 1984 Taiichi Yuasa and Masami Hagiya, 1993 Giuseppe Attardi, 2013 Juan J. Garcia-Ripoll, 2018 Daniel Kochmanski, 2024 Daniel Kochmanski and Marius Gerbershagen … ECL is free software, and you are welcome to redistribute it under certain conditions”. The licence itself is in the ECL source tree: LICENSE at tag 26.3.27 says LGPL version 2.1 or later (ECL’s LICENSE). The source id in the binary was not found in the GitHub mirror (it may be a commit of the port’s author), so the tag was used.
  • ECL’s LICENSE excludes from the LGPL the files src/lsp/loop.lsp, src/lsp/pprint.lsp and src/lsp/format.lsp, and the directories contrib/ and examples/. Parts of the following are present in libecl.so:
    • LOOP (src/lsp/loop.lsp, “Symbolic’s LOOP macro”): the file’s strings and internal names (for example LOOP-ACROSS-LIST, LOOP-EMIT-FINAL-VALUE, loop-minimax) are in the binary. The file carries permission notices of the Massachusetts Institute of Technology (1986) and Symbolics, Inc. (1989-1992) that ask for the notice to appear in copies and in supporting documentation. The notice is reproduced verbatim from ECL 26.3.27 in LICENSES/ECL-loop.lsp-notice.txt.
    • Pretty printer and FORMAT (pprint.lsp, format.lsp): names such as pretty-stream, pprint-logical-block and format-directive are in the binary. The files say they are from CMU Common Lisp and “placed in the public domain”.
    • contrib/ecl-cdb/ (copyright 2011 Juan Jose Garcia-Ripoll): libecl.so contains its ecl-cdb::* functions and the file names ECL-CDB.LISP and ECL-HELP.LISP. The files’ header says “GNU Library General Public License … version 2 of the License, or (at your option) any later version” (LICENSES/LGPL-2.0-or-later.txt).
    • Other contrib/ directories of ECL 26.3.27 (for example asdf, sockets and deflate): no names from them were found in libecl.so.
  • GMP: libecl.so exports GMP’s __gmpz_* and __gmpn_* functions, including internals that only exist in the GMP 4 series (for example __gmpn_kara_mul_n), and contains the string 4.2.1. ECL 26.3.27 bundles GMP 4.2.1 in src/gmp (PACKAGE_STRING='GNU MP 4.2.1'), whose files state the GNU LGPL “version 2.1 of the License, or (at your option) any later version”. Copyright: Free Software Foundation, Inc.
  • Garbage collector: libecl.so contains Boehm-GC banners (“Copyright 1988, 1989 Hans-J. Boehm and Alan J. Demers”, “Copyright (c) 2008-2021 Ivan Maidanski”, and others) and exports GC_* functions. ECL 26.3.27 bundles version 8.2.8 in src/bdwgc. The README and include/gc.h of bdwgc v8.2.8 give the “THIS MATERIAL IS PROVIDED AS IS … Permission is hereby granted to use or copy this program for any purpose, provided the above notices are retained on all copies …” terms, which are the text of SPDX Boehm-GC. The copyright lines in gc.h are: Hans-J. Boehm and Alan J. Demers (1988, 1989); Xerox Corporation (1991-1995); Silicon Graphics (1996-1999); Hewlett-Packard (1999, 2000-2011); Free Software Foundation (2007); Ivan Maidanski (2009-2020).
  • libffi is bundled in ECL’s source tree, but no libffi symbols are exported or imported by libecl.so or maxima.wasm, so it is not listed as shipped.
  • libecl.so also holds character tables generated from the Unicode Character Database files UnicodeData.txt and Jamo.txt (per ECL’s contrib/unicode scripts). ECL’s tree states no licence for these tables, and the terms of the Unicode data files were not examined here: not determined.

gnuplot

  • libgnuplot.so reports gnuplot version 6.1, patchlevel 0, date 2025-02-15, and “Copyright (C) 1986-1993, 1998, 2004, 2007-2023”. The licence text is gnuplot’s Copyright file, committed unchanged as LICENSES/gnuplot.txt from https://github.com/gnuplot/gnuplot (master as of 2023-09-08, fbeb88eadedf927a4d778b41dd118e373f33eacb). That GitHub mirror stopped at 2023-09-08, which is older than the shipped build, so the file could not be compared at the exact version; the SPDX gnuplot text matches it. The official gnuplot repository on SourceForge could not be read from the build environment.
  • libgnuplot.so exports a function libgnuplot_main. That name does not occur in gnuplot’s source at the commit above (gnuplot’s own entry points there are main and gnu_main), and the binary is dated 2025-02-15, after that commit. This suggests a modified, library-style build of gnuplot (or a newer upstream that could not be read). Where the sources or patches of that build are published was not determined.
  • gnuplot’s licence allows distributing binaries built from modified sources only if the source modifications are distributed as a patch file with the binaries, the version is identified, and contact information is kept. Whether the WebAssembly build of gnuplot is modified, and where any patches are published, was therefore not determined (see the previous point).
  • libgnuplot.so also contains parts of Emscripten’s musl libc (it exports crypt_r and the __crypt_* functions) and the path /emsdk/emscripten/system/lib/pthread/thread_profiler.c. It has no libc++, libc++abi or compiler-rt paths. These are covered by the “Emscripten system libraries” row.

Emscripten

  • maxima.js is Emscripten’s generated JavaScript glue. It has no licence header. Emscripten’s LICENSE offers MIT or the University of Illinois/NCSA licence; it was read at the main branch (45a6cffdbdf003665c7f48072191ce5a860fd0f4) because the toolchain version is not recorded in the files. maxima.wasm contains paths such as /emsdk/emscripten/system/lib/libcxxabi/src/, /emsdk/emscripten/system/lib/compiler-rt/lib/builtins/ and /emsdk/emscripten/system/lib/html5/; libgnuplot.so contains only /emsdk/emscripten/system/lib/pthread/thread_profiler.c.
  • musl is “licensed under the following standard MIT license”; its COPYRIGHT file also lists parts under other terms (for example the DES crypt code, which is under a BSD licence). The Emscripten tree’s LLVM libraries say “Apache License v2.0 with LLVM Exceptions”; the libc++ file also describes a dual MIT and University of Illinois licence for older parts. Which of these parts are in the shipped binaries was not examined.

STACK

STACK is developed at https://github.com/maths/moodle-qtype_stack. This site uses it at commit 33383047af39c204bf4442802a058f8b918b2b1b (16 October 2026). The earlier milestone-one material, the sample question exports described below, comes from commit 10d323311b7f39fb7b092dd10ce75f7d8632f525.

STACK’s own statement, at that commit: its doc/en/About/License.md says the source code is “Licensed under the GNU General Public, License Version 3” and links to COPYING.txt, which is only the text of the GNU GPL version 3 (the standard text, which has no “or later” grant of its own; GPL-3.0 text). Neither file grants STACK under “or any later version” (the phrase occurs in the GPL text itself only in its section 14 and appendix). The grant appears only in the headers of individual files: for example the PHP language file lang/en/qtype_stack.php, corsscripts/stackmplite.js (“either version 3 of the License, or (at your option) any later version”) and corsscripts/stackjsxgraph.js (“GNU GPL v3 or later”). So the project licence is recorded here as GPL version 3, and “or later” only where a file’s header says so. The sample questions are under Creative Commons Attribution-ShareAlike 4.0, except the HELM materials, which are under Creative Commons Attribution-NonCommercial 4.0.
