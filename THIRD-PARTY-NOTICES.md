# Third-party notices

The executable runtime and STACK source files are fetched into ignored working directories during the experiment; no upstream runtime binaries are committed.

That stays true for the repository. The published GitHub Pages site, however, does redistribute the runtime binaries and the STACK sources. It serves the Maxima, ECL and gnuplot WebAssembly runtime (`maxima-runtime/`: the binaries and `maxima.js` copied byte for byte from https://maxima-on-wasm.pages.dev/; `runtime-preload.json` is assembled by this project from those unmodified files), the STACK Maxima libraries (`stack-sources.json`), STACK JavaScript and sample questions, JSXGraph linked from shared native board assets (inlined in older previews), and the Quarto page libraries. The page `site/licenses.qmd` (published as `licenses.html`, "Licences and sources") lists each component with its version, licence, the evidence for that licence and the exact upstream source. The licence texts (27 files) are in `site/LICENSES/`. The same runtime files and the same STACK commit are also served in the preview copies under `previews/research/` (`2026-10-native-stack`, `2026-10-runtime-feasibility`); the page covers those copies too.
